# 로그인 기획

## 주요 기능

1. Google 로그인
2. 자동 로그인
3. 로그아웃

## 요구사항 정의

### 기능 요구사항

- 메인 화면 접근 전, 로그인 화면을 추가한다.
- 사용자는 Google 계정을 이용하여 로그인할 수 있어야 한다.
- 로그인 성공 시 / 로그인 상태에서 화면 클릭 시 메인 화면으로 이동해야 한다.
- 로그인 실패 또는 인증을 취소한 경우 로그인 화면을 유지해야 한다.
- 로그인 상태를 저장하여 종료 후에도 게임 재실행 시 로그인 상태로 바로 접속 가능해야 한다.
- 사용자는 로그아웃을 통해 로그인 정보를 삭제할 수 있어야 한다.

## 기능 명세

### 1. Google 로그인

Google OAuth 인증을 통해 사용자를 로그인하도록 구현한다. 인증이 완료되면 메인 화면으로 이동하며, 인증 실패 또는 취소 시 로그인 화면을 유지한다.

### 2. 자동 로그인

이전에 로그인한 정보가 저장되어 있는 경우 게임 실행 시 자동으로 로그인하여 메인 화면으로 이동하도록 구현한다. 저장된 로그인 정보가 없거나 유효하지 않은 경우 로그인 화면을 표시한다.

### 3. 로그아웃

로그아웃 버튼을 선택하면 저장된 로그인 정보를 삭제하고 로그인 화면으로 이동하도록 구현한다.
