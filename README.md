# gameQALearning
QA 프로세스 이해용 학습 프로젝트

## 프로젝트 목적

Unity를 활용하여 모바일 게임의 보편적인 기능들을 구현해보면서 기능 개발, 테스트, 버그 수정 과정에서 QA 프로세스 전반을 경험하는 것을 목표로 한다.

## 프로젝트 진행 방법

각 기능은 다음과 같은 단계로 진행한다.

1. 기획 및 요구사항 정의
2. 기능 명세 작성
3. 기능 개발
4. (QA) Test Case(TC) 작성
5. (QA) Checklist(CL) 작성
6. Checklist를 통한 기능 테스트 
7. (버그 발생 시) 버그 수정
8. 재테스트
